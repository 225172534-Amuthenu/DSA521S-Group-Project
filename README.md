Project Description



This project is a NUST Service Centre Simulation developed for the DSA521S course.



The project demonstrates the implementation and application of different data structures and algorithms to simulate a campus service-centre environment.



Data Structures



The project implements:



\* Queue

\* Singly Linked List

\* Stack

\* Array



Sorting Algorithms



The project implements and evaluates:



\* Selection Sort

\* Insertion Sort

\* Merge Sort

\* Quick Sort

How to Compile



Open PowerShell in the project folder and run:



```bash

javac -d out src\\\*.java

```



How to Run



After successful compilation, run:



```bash

java -cp out Main

```
